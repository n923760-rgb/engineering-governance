# Pre-Task Checklist

- [ ] Current owner instruction is clear.
- [ ] Primary task type is exactly one of the supported task types.
- [ ] Repository identity is verified.
- [ ] Applicable repository instructions are read.
- [ ] Official branch is verified.
- [ ] Remote official HEAD is verified.
- [ ] Local branch and local HEAD are verified.
- [ ] Working tree state is known.
- [ ] Existing PR state, head SHA, and base branch are verified when applicable.
- [ ] If no PR is expected for the work branch, no conflicting open PR exists.
- [ ] Relevant CI state is known when applicable.
- [ ] Scope is atomic.
- [ ] Out-of-scope systems are named.
- [ ] Protected actions are explicit.
- [ ] Stop conditions are explicit.
- [ ] Validation can actually prove the requested contract.
- [ ] New MCP servers, skills, plugins, or tool permissions have an approved inventory and provenance, if applicable.
- [ ] Any security advisory is matched to deployed artifacts and reachable paths; unknown runtime evidence is stated.
- [ ] CI event/trust boundary, token/OIDC scope, transitive action dependencies and untrusted PR inputs are checked if affected.
- [ ] Agent tool policy, unexpected secondary calls, audit redaction and sandbox qualification are scoped if affected.
