# CI Failure Checklist

- [ ] Inspect the complete failure chain.
- [ ] Identify the first causal failure.
- [ ] Separate dependent/secondary failures.
- [ ] Inspect relevant logs and artifacts.
- [ ] Reproduce locally when reasonably possible.
- [ ] Fix the root cause, not only the visible symptom.
- [ ] Review the entire resulting diff.
- [ ] Rerun only the verification needed to prove the correction.
