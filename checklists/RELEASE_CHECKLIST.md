# Release Checklist

Release, tag, signing, and production deployment are protected actions unless explicitly authorized.

- [ ] Release authority is explicit.
- [ ] Exact release SHA is recorded.
- [ ] Required tests and CI passed.
- [ ] Runtime qualification is complete where required.
- [ ] Artifact checksums are recorded.
- [ ] Secrets are not present in artifacts or reports.
- [ ] Rollback procedure is documented.
- [ ] Release evidence is retained.
